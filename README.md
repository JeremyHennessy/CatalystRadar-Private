# Private research price history
Only the thin private workflow, secret and licensed data belong here. Shared collector code, synthetic tests, development and public dashboard live in JeremyHennessy/CatalystRadar. The private workflow pins a reviewed public commit; no test suite runs here. Raw quotes, data-derived returns and secrets never go to public artifacts or commits.

Owner-only personal use. No brokerage or trades. Immutable raw daily snapshots are not total-return, auction or historical point-in-time data. Base64 preserves bytes, not encryption. Privacy depends on private GitHub access.

The single private consumer verifies repository privacy and access, public-consumer retirement and cross-repository recent request reservations. No force pushes or paid plan. Bounded daily trial runs Nov16–21,2026. Failed collection does not commit partial files. See the public docs/private-retention.md for design and licensing limitations.
